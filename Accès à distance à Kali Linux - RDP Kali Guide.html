Accès à distance Kali Linux

Robert Agar Auteur de l'article
  • AideWire
  • →

  • →

  • →
  • Accès à distance Kali Linux

Le bureau à distance Linux  sur Kali est compatible avec de nombreux systèmes et appareils (comme Remmina, le serveur VNC, le serveur Xrdp, etc.)

Par exemple,  Xrdp  fournit un gestionnaire de session très pratique appelé « Xrdp sesman ». Xrdp sesmen permet aux utilisateurs de gérer les sessions utilisateur via des options d'authentification, permettant un meilleur contrôle sur qui peut accéder à la machine distante !

Certains outils d'accès à distance offrent même des options pratiques de redirection de port (la redirection de port dirige le trafic externe vers le bon serveur au sein d'un réseau local.)

Mais, sur une variété sélectionnée de ces systèmes d'exploitation, les utilisateurs peuvent n'avoir accès qu'à une installation minimale et peuvent ne pas avoir (parfois) d'accès direct aux interfaces graphiques telles que WSL.

Lorsque vous effectuez une installation de Kali Linux, SSH,  XRDP et VNC  sont installés par défaut. Les services ne sont pas activés et devront être démarrés avant de pouvoir accéder à distance au système Kali Linux à partir d'une autre machine.

Comment établir un accès à distance à Kali Linux – solution native

Les étapes suivantes sont nécessaires pour implémenter un bureau distant Kali Linux.

  1. Obtenez l'adresse IP du système Kali Linux.
  2. Choisissez le protocole que vous utiliserez pour configurer une connexion au bureau à distance Kali. (SSH, XRDP ou VNC).
  3. Configurez et utilisez l'outil sélectionné sur votre système Kali Linux.

Cependant, cela ne signifie pas que votre expérience Kali Linux RDP ne peut pas être flexible et efficace. L'accès à Kali RDP et SSH peut être effectué de différentes manières, et nous avons décrit ci-dessous les outils les plus populaires pour activer les options de bureau à distance Kali Linux. Ces outils permettent aux utilisateurs de Kali d'utiliser un terminal ou d'accéder à un contrôle complet du bureau à distance.

Que pouvez-vous faire une fois que vous avez accès à distance à Kali Linux ?  Contrôlez et gérez les fichiers, les paramètres et bien plus encore des appareils distants ! Ce n’est pas seulement un outil pratique, mais aussi un outil crucial à l’ère moderne du travail à distance.

Étant donné que Kali (et le système d'exploitation alternatif de la machine Linux, Ubuntu) peut fonctionner avec une pléthore de clients de bureau à distance Kali Linux comme  Remmina , le serveur VNC, le serveur Xrdp Zoho Assist, et plus encore… C'est une excellente idée pour les utilisateurs de machines Linux d'activer la télécommande. capacités Kali de bureau.

Remarque :   il est important de s'assurer que le téléchargement/l'installation/la mise à jour de tous les packages nécessaires est terminé avant d'essayer de connecter un bureau distant Kali Linux à des machines Windows (ou vice versa).

L'outil, Sudo Apt, sera utile pour l'aide à distance sur les packages Linux. Une fois que l'utilisateur exécute la  commande Sudo apt-get update  , tous les packages requis seront téléchargés directement à partir du Web.

Il est essentiel de vérifier que toutes les applications/outils aidant au bureau à distance Windows à partir des connexions Kali Linux sont également compatibles.

Configuration de RDP avec XFCE

Une méthode simple pour accéder à une interface graphique Kali Linux d’accès à distance consiste à installer XFCE et à établir RDP. XFCE a débuté en 1966. Le créateur de XFCE, nommé Oliver Fourdan, a lancé le programme pour la première fois au milieu des années 60.

Il souhaitait fournir une version plus récente des systèmes d'exploitation Linux pour fonctionner sur l'environnement de bureau. XFCE, à l’origine, était un acronyme symbolisant X formant un environnement commun.

Cela se fait soit manuellement, soit avec le script fourni  ici  (illustré ci-dessous) :

#!/bin/sh
echo "[+] Installing Xfce, this will take a while"
apt-get update
apt-get dist-upgrade -y
apt-get install -y kali-desktop-xfce xrdp

 

echo "[+] Configuration de XRDP pour écouter le port 3390 (mais pas démarrer le service)…"
sed -i 's/port=3389/port=3390/g' /etc/xrdp/xrdp.ini

Procédez comme suit pour utiliser le script :

kali@kali:~$ wget https://gitlab.com/kalilinux/build-scripts/kali-wsl-chroot/-/raw/master/xfce4.sh
kali@kali:~$
kali@kali:~$ chmod +x xfce4.sh
kali@kali:~$
kali@kali:~$ sudo ./xfce4.sh
kali@kali:~$

Connexion au bureau à distance La configuration manuelle de Kali Linux offre plus de contrôle sur l'accès à distance aux paramètres de configuration des machines Kali Linux, mais nécessite un peu plus de temps. Pour ceux qui utilisent WSL, une fois XFCE et RDP configurés, les utilisateurs doivent démarrer le service et se connecter.

kali@kali:~$ sudo systemctl enable xrdp --now
kali@kali:~$

Pour les utilisateurs WSL, dbus-x11 doit être installé ensuite pour permettre à Xrdp et XFCE de se connecter :/

kali@kali:~$ sudo apt install -y dbus-x11
kali@kali:~$

Exécutez la commande suivante pour démarrer le service :

kali@kali:~$ sudo /etc/init.d/xrdp start
kali@kali:~$

Les utilisateurs du bureau à distance vers Kali se connectent ensuite au client RDP lié au système particulier (les utilisateurs doivent également noter le port utilisé.) Si le script ci-dessus était utilisé, le port serait 3390.

Remarque sur les outils Kali Linux d'accès à distance avec IP :  Dans le cas de WSL, l'IP est 127.0.0.1:3390 pour les utilisateurs souhaitant se connecter à/depuis des machines Windows.

La configuration de RDP sur Kali Linux dépend du système sur lequel Kali s'exécute. Un exemple est Docker qui nécessite une commande de lancement telle que :

docker run -p 3390:3390 --expose=3390 --tty --interactive KaliLinux/Kali-rolling /bin/bash

Effectuer des activités telles que la reprise d'un conteneur quitté est possible lors de la mise en œuvre d'une connexion Kali Linux RDP avec Docker.

Si la connectivité Kali RDP implique des instances cloud AWS, la machine doit être configurée pour permettre à l'ordinateur distant d'accéder aux ports nécessaires.

Accès au bureau à distance (GUI) à Kali

Une fois que vous avez sélectionné les outils Kali Linux souhaités pour accéder aux ordinateurs distants, ouvrez une fenêtre de terminal et exécutez les commandes suivantes dans Kali OS. Ce qui suit décrira comment configurer l'accès à l'interface graphique pour les machines distantes.

Remarque :  Si vous avez déjà un utilisateur ou si vous souhaitez simplement utiliser root, ignorez le chemin de création d'utilisateur.

  • •  adduser tdh – Ajouter un utilisateur pour la connexion à distance
  • • Définir un mot de passe et d'autres informations
  • •  u sermod -aG sudo tdh – Obtenez une liste mise à jour des packages installables
  • •  apt-get update – Obtenez une liste mise à jour des packages installables
  • •  apt-get install xrdp – Installer le serveur RDP
  • •  systemctl start xrdp – Démarrez le serveur XRDP de base
  • •  systemctl start xrdp-sesman – Démarrez le gestionnaire de sessions XRDP

Les utilisateurs peuvent activer XRDP pour qu'il démarre automatiquement lorsque la machine s'allume en entrant les commandes suivantes :

  • • systemctl enable xrdp
  • • systemctl enable xrdp-sesman

Comment configurer RDP pour les machines distantes Windows

  1. Étape 1 :  ouvrez la connexion Bureau à distance sur la machine Windows

  2. Étape 2 :  Entrez l'adresse IP de la machine Kali et cliquez sur Connecter

  3. Étape 3 :  Quittez la session sur Xorg et cliquez sur « OK » après avoir saisi les informations d'identification requises.

Remarque :   Si les utilisateurs rencontrent un écran vide : redémarrez la machine mais ne vous connectez pas. Connectez-vous uniquement avec un bureau distant : cela est dû à plusieurs sessions (une distante et une locale.)

Après avoir résolu ce problème Linux distant de « deuxième session », autorisez autant de sessions que vous le souhaitez en procédant comme suit : Edit  “/etc/xrdp/startwm.sh”, puis ajoutez la ligne susmentionnée  avant  les lignes qui testent et exécutent Xsession.

Bien que  $HOME/.profile  ne fasse pas partie de la solution,  « $HOME/.profile »  doit toujours s'exécuter avant de démarrer une session.

  • • désactiver DBUS_SESSION_BUS_ADDRESS
  • • désactiver XDG_RUNTIME_DIR
  • • . $HOME/.profil

VNC pour le bureau à distance Kali

VNC est une solution de bureau à distance alternative à RDP pour Kali Linux. Le protocole est installé par défaut avec Kali Linux mais nécessite la définition d'un mot de passe avant d'utiliser l'outil.

Une différence majeure entre VNC et XRDP est qu'avec XRDP, une nouvelle session est établie lorsque vous vous connectez à distance et que vos informations de connexion sont requises. VNC vous permet de prendre le contrôle de la session en cours tant que vous pouvez fournir un mot de passe VNC.

VNC est un outil préféré des équipes de support technique. Ils l'utilisent pour effectuer un bureau à distance sur un système Kali, identifier le problème et le résoudre pendant que l'utilisateur surveille l'activité de l'écran.

Utilisez la  vncserver commande pour créer le mot de passe VNC.

Lorsque vous démarrez VNC pour la première fois, vous devez fournir le mot de passe. Vous recevrez l’URL de la session pour y accéder. Si vous rencontrez des problèmes, consultez cet article de SuperUser.

Vous pouvez activer SSH et démarrer VNC à partir de là s'il ne démarre pas automatiquement. Une fois que VNC est activé et que vous avez l'URL, vous pouvez vous y connecter pour établir un bureau distant sur le système Kali Linux.

XRDP et VNC vous donnent un accès complet à l'interface du système. Une différence avec XRDP est qu'avec une connexion VNC, l'activité de l'écran sera visible sur l'ordinateur distant. Les utilisateurs peuvent surveiller l'activité et interagir à l'aide du clavier ou de la souris. XRDP crée une nouvelle session qui n'est pas visible pour les utilisateurs qui surveillent physiquement la machine distante.

Fermez toujours la session VNC lorsque vous avez terminé.

Accès au terminal via SSH

Depuis le système d'exploitation Kali, ouvrez une fenêtre de terminal et exécutez les commandes suivantes :

  • •  adduser tdh – Ajoutez un utilisateur pour la connexion à distance.
  • • Définir un mot de passe et d'autres informations
  • •  usermod -aG sudo tdh – Obtenez une liste mise à jour des packages installables
  • •  systemctl start ssh – Démarrez le serveur ssh de base

Utilisez Putty sous Windows pour vous connecter à Kali via SSH

Les utilisateurs peuvent démarrer automatiquement avec la commande : « systemctl activate ssh » .

Ceci conclut le guide sur l'activation du bureau à distance et de l'accès SSH à Kali.

Pour finir :  n'oubliez pas de redémarrer et de mettre à niveau la machine, que vous utilisiez un système d'exploitation Kali, Ubuntu ou Windows.
